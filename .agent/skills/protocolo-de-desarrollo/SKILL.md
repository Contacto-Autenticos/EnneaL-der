# Protocolo de Desarrollo (6 Fases)

Sigue estrictamente este protocolo para cada solicitud de desarrollo o modificación de código.

## FASE 1: INVESTIGACIÓN DEL PROBLEMA (Discovery)
* **Objetivo:** Entender profundamente el "por qué" y el "qué".
* **Acción:** Analiza la solicitud. Si es insuficiente, haz preguntas de aclaración sobre público objetivo, propósito, restricciones técnicas y contexto.
* **Salida:** Resumen del problema y requisitos clave.

## FASE 2: PLANIFICACIÓN (Roadmap)
* **Objetivo:** Estructurar la lógica antes de la acción.
* **Acción:** Desglose de tareas paso a paso. Define el Tech Stack. Crea estructura de archivos/base de datos.
* **Salida:** Plan de acción enumerado y arquitectura propuesta.

## FASE 3: DISEÑO (UI/UX)
* **Objetivo:** Visualizar la solución.
* **Acción:** Utiliza siempre las capacidades de diseño disponibles.
* **Salida:** Descripción detallada del diseño visual y la experiencia de usuario.

## FASE 4: EJECUCIÓN (Coding)
* **Objetivo:** Materializar la solución.
* **Acción:** Escribe código limpio, modular, moderno y comentado basándote en FASE 2 y 3.
* **Salida:** Bloques de código completos.

## FASE 5: REVISIÓN (Testing & Debugging)
* **Objetivo:** Análisis crítico.
* **Acción:** Simula ejecución. Busca vulnerabilidades, errores lógicos o de rendimiento.
* **Salida:** Reporte de "Auto-Auditoría".

## FASE 6: CORRECCIÓN (Refinement)
* **Objetivo:** Entrega final pulida.
* **Acción:** Corrige errores de FASE 5 o proporciona sugerencias de mejora e instrucciones de despliegue.
* **Salida:** Código final o instrucciones.

---

**Regla de Interacción:**
- **Solicitudes Complejas:** Detente tras la **FASE 3** y pide confirmación.
- **Solicitudes Simples:** Ejecuta las 6 fases de corrido, etiquetando cada una.
